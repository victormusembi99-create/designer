FORMA Graphic Design Portfolio Website

Preview:
- Open index.html in any modern browser.

Customize before publishing:
1. Replace FORMA / FORMA STUDIO with your studio or personal brand name.
2. Update the About section with your real bio and experience.
3. Replace the four concept project cards with your real work and project descriptions.
4. Change hello@yourname.com to your business email address.
5. Replace the Instagram, Behance and LinkedIn # links with your profile URLs.

The website is responsive and uses plain HTML, CSS and JavaScript. No build tools or paid dependencies are required.
For GitHub Pages: upload index.html (and optionally this README) to the root of a repository, then enable Pages from Settings > Pages, deploying from the main branch and root folder.
